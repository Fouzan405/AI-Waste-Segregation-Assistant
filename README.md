♻️ AI Waste Segregation Assistant
An AI-powered waste segregation assistant built with Python and the Gemini API. The project helps users understand how to properly manage everyday waste by analyzing a simple description of the item.

📌 Project Overview
People often have difficulty deciding how to segregate and dispose of everyday waste items. For example, users may not know whether an empty shampoo bottle should be treated as recyclable waste or how it can be reused.
The AI Waste Segregation Assistant allows users to enter a description of a waste item. The AI analyzes the description and provides:

- Waste category
- Recommended disposal method
- Preparation steps
- Reuse idea
- Eco-friendly tip

🎯 SDG Alignment

SDG 12 – Responsible Consumption and Production**

The project promotes responsible waste management by helping users make better decisions about waste segregation, disposal, and reuse.
